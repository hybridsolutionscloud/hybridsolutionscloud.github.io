# Repo intent — hybridsolutionscloud.github.io

**The public marketing site for Hybrid Cloud Solutions, LLC.**

## What this repo is

The company website for Hybrid Cloud Solutions, LLC — founded by Kristopher Turner
(Microsoft MVP, MCT) — describing its Azure Local / Azure Arc / Hyper-V / AVD hybrid
cloud consulting. Built on Astro + Tailwind (the AstroWind theme), deployed via
GitHub Pages.

## Shape

- Standard Astro project layout (`src/`, `public/`, `astro.config.ts`)
- Also carries Docker/Netlify/Vercel/StackBlitz config — several deploy targets are
  configured even though GitHub Pages is the only one the README names as live
- `.frontmatter/` — Front Matter CMS config for content editing

## What this repo is not

- Not the product/tooling org — the actual HCS products (azure-scout, stagecoach,
  vault-prospector, etc.) live under the separate **`Hybrid-Solutions-Cloud`** GitHub org
  (note the dashes). This repo's org, `hybridsolutionscloud` (no dashes), is a distinct,
  marketing-site-only account — easy to confuse with the product org by name alone.

## Status

Active — public marketing site.
